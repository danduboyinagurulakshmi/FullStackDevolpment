🔹 1. Class & Object
1. What is a class?

A class is a blueprint used to create objects. It defines properties (variables) and behaviors (methods).

2. What is an object?

An object is an instance of a class that contains real values and occupies memory.

3. What is the difference between class and object?

A class is a logical entity, whereas an object is a physical entity that occupies memory.

4. How is memory allocated to objects?

Memory is allocated in the heap area when an object is created using the new keyword.

5. What is the lifecycle of an object?

Creation → Memory allocation → Usage → Garbage collection (destruction).

🔹 2. Encapsulation
1. What is encapsulation?

Encapsulation is wrapping data and methods into a single unit (class).

2. How do we achieve encapsulation?

By declaring variables as private and providing public getter and setter methods.

3. Why is encapsulation important?

It protects data from unauthorized access and improves security.

4. What is data hiding?

Restricting direct access to variables using access modifiers.

5. What happens if encapsulation is not used?

Data can be modified directly, leading to security and maintenance issues.

🔹 3. Abstraction
1. What is abstraction?

Abstraction hides implementation details and shows only essential features.

2. How is abstraction achieved?

Using abstract classes and interfaces.

3. Can an abstract class have constructors?

Yes, abstract classes can have constructors.

4. What is the benefit of abstraction?

It reduces complexity and improves maintainability.

5. What happens if a class does not implement abstract methods?

The class must be declared abstract.

🔹 4. Inheritance
1. What is inheritance?

Inheritance allows one class to acquire properties and methods of another class.

2. What is IS-A relationship?

It represents inheritance. Example: Dog IS-A Animal.

3. What is the use of super keyword?

It is used to refer to parent class variables, methods, or constructors.

4. Can constructors be inherited?

No, constructors are not inherited.

5. What is method overriding?

When a child class provides its own implementation of a parent class method with the same signature.

🔹 5. Polymorphism
1. What is polymorphism?

Polymorphism means one method behaving differently in different situations.

2. What are types of polymorphism?

Compile-time (overloading) and runtime (overriding).

3. What is method overloading?

Same method name with different parameters in the same class.

4. What is method overriding?

Redefining parent class method in child class.

5. What is dynamic binding?

Method call resolved at runtime instead of compile time.

🔹 6. Constructors
1. What is a constructor?

A special method used to initialize objects.

2. What are types of constructors?

Default and parameterized constructors.

3. What is constructor chaining?

Calling one constructor from another using this() or super().

4. Can a constructor be private?

Yes, used in Singleton design pattern.

5. What happens if no constructor is defined?

Compiler provides a default constructor.

🔹 7. Association, Aggregation & Composition
1. What is association?

A relationship between two classes. Example: Teacher and Student.

2. What is aggregation?

A weak relationship where child can exist independently. Example: Library and Books.

3. What is composition?

A strong relationship where child cannot exist without parent. Example: House and Rooms.

4. What is HAS-A relationship?

It represents association or composition.

5. When should composition be preferred over inheritance?

When you want flexibility and loose coupling.

🔹 8. Overloading vs Overriding
1. What is the main difference?

Overloading → Same class, different parameters.
Overriding → Different class, same method signature.

2. Can we overload by changing return type only?

No.

3. Can static methods be overridden?

No, they are method hidden.

4. What is covariant return type?

Child class can return a subclass type in overriding.

5. What happens if final method is overridden?

It causes a compile-time error.

🟢 BASIC LEVEL – OOPS Fundamentals in Java
1. What is OOPS?

Object-Oriented Programming System is a programming paradigm based on objects, which contain data (variables) and methods (functions).

2. What are the four pillars of OOPS?

Encapsulation

Abstraction

Inheritance

Polymorphism

3. What is a class in Java?

A class is a blueprint or template used to create objects.

4. What is an object?

An object is an instance of a class that contains state and behavior.

5. What is Encapsulation?

Binding data and methods together into a single unit (class) and restricting access using access modifiers.

6. What is Abstraction?

Hiding implementation details and showing only essential features.

7. What is Inheritance?

A mechanism where one class acquires properties of another class using extends.

8. What is Polymorphism?

The ability of an object to take many forms.

Types:

Compile-time (Method Overloading)

Runtime (Method Overriding)

9. What is method overloading?

Same method name with different parameters in the same class.

10. What is method overriding?

Subclass provides specific implementation of a method already defined in parent class.

🔵 ADVANCED LEVEL – Interview Focused Questions
23. What is dynamic method dispatch?

Runtime polymorphism mechanism where overridden method is called at runtime using parent reference.

24. Can we override static methods?

No. Static methods are resolved at compile time.

25. Can we override private methods?

No. Private methods are not inherited.

26. What is object slicing?

When subclass object is assigned to parent object and subclass-specific properties are lost.

27. What is covariant return type?

When overridden method returns subclass type instead of parent type.

28. What is marker interface?

An empty interface used to mark a class (Example: Serializable, Cloneable).

29. What is tight coupling and loose coupling?

Tight coupling → Classes are highly dependent

Loose coupling → Classes are independent (using interfaces)

30. What is composition in Java?

A "has-a" relationship where one class contains another class object.

31. What is aggregation?

A weak "has-a" relationship where objects can exist independently.

32. What is difference between == and equals()?

== → compares memory reference

equals() → compares object content

33. Why is Java not 100% object-oriented?

Because it supports primitive data types (int, char, float, etc.).

34. What is Object class?

Root class of Java. Every class implicitly extends Object.

Important methods:

toString()

equals()

hashCode()

35. What is Singleton class?

A class that allows only one object creation.
