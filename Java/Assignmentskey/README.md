# ☕ Java Full Stack – Core Concepts & Assignments

This repository contains **Java programming assignments and implementations** covering core concepts required for **Full Stack Development**, academic coursework, and interview preparation.

The code is written with clarity, proper structure, and beginner-friendly logic.

---

## 📌 Topics Covered

### 🔢 Arrays
- Frequency of each number in an array
- Count distinct elements
- Find maximum element
- Sum of odd elements
- Find duplicate element (without using inbuilt methods)

---

### 🧱 Object-Oriented Programming (OOPS)
- Class and Object
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction

---

### ⚠️ Exception Handling
Demonstration of **runtime exceptions** with proper `try-catch` handling:
- ArithmeticException (Division by zero)
- NullPointerException
- ArrayIndexOutOfBoundsException
- NumberFormatException
- ClassCastException

Each program prints **meaningful error messages** and avoids program crashes.

---

### 🧵 Multithreading & Synchronization
- Shared `BankAccount` class
- Multiple threads attempting withdrawals
- Synchronized method to prevent inconsistent balance
- Handling insufficient balance safely

---

### 🎞️ Abstraction – Media Library
- Abstract class `Media`
- Implementations:
  - Book
  - Movie
  - Song
- Demonstrates **dynamic method dispatch**

---

### 🎛️ Interface-Based Programming
**Smart Device Control System**
- Interface: `RemoteControl`
- Implementations:
  - TV
  - AC
  - Speaker
- Demonstrates loose coupling and polymorphism

---

### 📐 Matrix Problems
- Diagonal Traversal of a Square Matrix
- Zig-Zag Traversal of a Matrix
